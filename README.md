## 🚀 درباره پروژه

نیورا یک **ابراپلیکیشن محلی (Local Super-App)** به‌صورت نمونه‌ی اولیه (Prototype) است که شامل بخش‌های زیر است:

- 🎮 **مرکز بازی (Game Hub):** ۶ بازی
- 🏆 **تورنمنت‌ها:** مسابقات بین کاربران
- 💬 **کامینیتی و پیام‌رسان امن:** گفتگو و پیام‌رسانی
- 👛 **کیف پول:** مدیریت موجودی داخلی
- ⚙️ **تنظیمات:** قفل با رمز PIN (بعد از ۳ تلاش اشتباه، ۳۰ دقیقه قفل می‌شود)
- 🖼️ **پروفایل:** انتخاب آواتار از گالری و تغییر رایگان شناسه (ID)
- 💎 **فروشگاه اشتراک VIP:** خرید اشتراک ویژه

## ⚠️ وضعیت فعلی پروژه

نیورا در حال حاضر یک **نمونه‌ی اولیه‌ی فرانت‌اند / رابط کاربری (UI Prototype)** است:

- داده‌ها فقط در `localStorage` مرورگر ذخیره می‌شوند
- **هیچ سرور واقعی یا بک‌اندی وجود ندارد**
- هدف فعلی، نمایش طراحی و منطق رابط کاربری است

## 🛠️ اجرای محلی

```bash
npm install
npx http-server -p 3000
# یا
npm start
```

سپس در مرورگر باز کنید:

```
http://127.0.0.1:3000
```

> 💡 توسعه‌ی این پروژه روی اندروید با Termux انجام شده؛ روی هر سیستم‌عاملی با Node.js قابل اجراست.

## 📁 ساختار فایل‌ها

```
Ebi-tiem/
├── index.html      # صفحه اصلی برنامه
├── style.css       # استایل‌ها (رابط کاربری)
├── script.js       # منطق و رفتار برنامه
├── server.js       # سرور ساده محلی
└── package.json    # وابستگی‌ها و اسکریپت‌ها
```

## 🧹 نکته درباره node_modules

پوشه‌ی `node_modules` نباید در مخزن کامیت شود. اگر به‌اشتباه کامیت شده، این دستورات را اجرا کنید:

```bash
git rm -r --cached node_modules
echo "node_modules/" >> .gitignore
git commit -m "Remove node_modules from repo"
```
